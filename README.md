# Color Duel 1.0

## Режим техника

Браслет с ролью `technician` открывает настройки в любой фазе игры, при заполненном
лобби и заблокированной станции. Требуется обновить исходники Gateway вместе с игрой;
существующий API сотрудников сервера не менялся. Текущий раунд прерывается со статусом
`abandoned`; после закрытия остаётся пустое лобби. Окно не закрывается по таймеру
или повторному сканированию. В предпросмотре используйте **777 + Enter** из любого
окна или кнопку «Техник 777» в панели.

Оба экрана показывают общие настройки, счётчики и мастер подсветки. Доступны шесть языков.

- «Назначить» ожидает следующую кнопку единственного USB-геймпада (индексы 0–127).
  Занятая кнопка меняется местами с прежним назначением целевого цвета.
- Счётчик каждого цвета считает отдельные нажатия: 0…15, затем снова 0.
  Удержание не увеличивает счётчик. Программного подавления быстрых повторов нет.
- Поле COM принимает `COM1`, `COM2` и т. д.; `auto` ищет LED-плату, `off` отключает её.
  «Применить» сохраняет порт и переподключает контроллер.
- «Установить подсветку» запускает белую волну на физическом канале 1. Нажмите круг
  в реальном углу, где она видна. Повторите для каналов 2…8. Назначения сохраняются
  после всех восьми шагов; отмена сохраняет прежние настройки.
- Обычное нажатие круга запускает один белый бегущий огонь на назначенном канале.
- Блокировка сохраняется сервером StriveX; управлять ею может авторизованный техник.

Кнопки, каналы, COM-порт и язык сохраняются в `technician-settings.json` в пользовательском
каталоге приложения. У предпросмотра отдельный постоянный каталог `Color-Duel-Preview`.

### LED Arduino: прошивка V2

Для нового управления нужно загрузить обновлённый скетч
`arduino/ColorDuel_LED_Nano/ColorDuel_LED_Nano.ino` с библиотекой Adafruit NeoPixel.
Одна Nano обслуживает восемь линий D8, D9, D10, D11, D6, D7, A0, A1, по 60 диодов.
Скорость — **115200**. В обозначениях `A0` и `A1` используется латинская буква `A`.
Прошивка отвечает `COLOR_DUEL_LED_V2 READY`; старый LED-скетч не подходит.

Порядок компонентов установленных лент задан в `LED_TYPE`: `NEO_BRG` (B,R,G).
Он выбран по наблюдению: при прежнем `NEO_GRB` красный был верным, зелёный
становился синим, синий — бирюзовым, жёлтый — фиолетовым. После загрузки проверьте
все четыре цвета на физических лентах. Для лент другого типа изменяется `LED_TYPE`,
а не назначение кнопок или каналов. Команды ПК используют логические цвета
`R/G/B/Y/W`; палитра прошивки — чистые красный, зелёный, синий, жёлтый и белый.

ПК объединяет команды в кадры с подтверждением после вывода на все восемь линий.
Близкие и одновременные удары запускают независимые импульсы. В ожидании Arduino
случайно запускает разноцветные импульсы, сохраняя цвет каждого до конца.
На Game Over, результатах и лидерах каналы победителя зелёные, проигравшего красные;
при ничьей оба белые. Разрыв связи гасит подсветку через две секунды.

Проверки: `npm.cmd run check`, `npm.cmd run check:preview`, `npm.cmd run check:technician`.
UI-проверка использует эмуляцию USB и Arduino, физические ленты проверяются отдельно.

## Просмотр визуала без сборки EXE

Запустите `scripts\start-design.bat` или `npm.cmd run design` из папки Color-Duel.
Откроются два перемещаемых окна рядом: управление и экран игроков.
Закрытие любого окна завершает предпросмотр. F12 открывает инструменты разработчика.

- В любом окне наберите `111` и Enter, затем `222` и Enter — добавятся Алекс и Мира.
- В углу окна управления есть панель экранов: лобби, правила, ожидание,
  отсчёт, игра, Game Over, результаты и лидеры. Панель сворачивается в кнопку 🧪.
- В панели также есть кнопки браслетов, выбор четырёх игровых режимов,
  цветные кнопки игроков и полный запуск раунда.
- Удары с клавиатуры: игрок 1 — Q/W/E/R, игрок 2 — U/I/O/P.
  Цвета: красный, зелёный, синий, жёлтый. Клавиатура работает в обоих окнах.
- Поддерживается **один USB-геймпад для двух игроков**. Кнопки 1–4 (индексы 0–3)
  — игрок 1; кнопки 5–8 (индексы 4–7) — игрок 2, в том же порядке цветов.
  Считывается только один контроллер; удержание не повторяет удар, одновременные
  нажатия принимаются. Подключённый контроллер отображается в тестовой панели.
  После подключения нажмите и отпустите кнопку, чтобы контроллер обнаружился.
- Сохранение CSS обновляет оформление обоих окон, сохраняя экран и игроков.
  Изменение HTML/JS перезагружает окна и очищает демо-сессию.
  После изменения `main.js`, `preload.js` или `config.json` перезапустите просмотр.

В предпросмотре используется внутренний демо-Gateway. COM-платы по умолчанию отключены;
LED Arduino можно подключить в режиме техника, выбрав COM-порт.
Результаты просмотра сохраняются отдельно от обычной игры, реальные XP не начисляются.
`999` + Enter проверяет неизвестный браслет; `000` + Enter — ошибку связи.

В тестовом интерфейсе применены общие правки TNT: фиксированные списки по пять
строк, «Уровни», неподвижный «Старт», скрытие подсказки при двух игроках,
запуск сразу с отсчёта, таймер самого раунда и очистка пары после результатов.
В таблице лидеров скрыты выбор языка и возврат. Карточки результатов адаптированы
к вертикальному окну. Новые переходы и оформление включены только в тестовом режиме.

`scripts\start-interface-test.bat` включает тот же демо-интерфейс в полноэкранных окнах.
Для проверки: `npm.cmd run check` и `npm.cmd run check:preview`.
Установщик для этих изменений собирать не требуется.

Color Duel — отдельный Windows-аттракцион на базе проверенной архитектуры Lightning. Он использует два полноэкранных окна, StriveX Gateway/RFID, два Arduino Nano и два игровых режима.

## Оборудование

- Windows-ПК с сенсорным монитором и дополнительным игровым экраном.
- RFID-считыватель подключён к StriveX Gateway.
- Arduino Nano LED: восемь независимых WS2812-линий по 60 диодов.
- Arduino Nano Sensors: восемь HX711 с тензодатчиками.
- По четыре макивары у каждого игрока: красная, зелёная, синяя и жёлтая.

## Режимы

### Цветовая комбинация

Оба игрока видят одну комбинацию. Длина: 5/6/7/8 цветов. Неверный цвет сбрасывает ввод только ошибившегося игрока. Первый полностью повторивший комбинацию получает балл, затем создаётся новый раунд.

### Ритм-дуэль

Цветные ноты движутся сверху вниз. Звук воспроизводится при появлении ноты сверху, удар принимается в окне ±500 мс у нижней линии. Есть:

- общие партии для двух игроков;
- равные по числу нот сольные партии игроков;
- одновременно не более двух цветов; на лёгком уровне только один;
- доля двойных сочетаний от всех моментов попадания за раунд: средний — не более 10%, сложный — 30%, экстрим — 60%; лимит округляется вниз, пары распределяются случайно;
- финальное пятисекундное соло по двум цветам;
- `OK` при попадании и красная вибрация при промахе.

Итог определяется сначала по точности, затем по числу попаданий.

### Пин-понг

Игроки набивают независимые мячи цветными ракетками. Чтобы запустить мяч или отбить его после возвращения, нужно нажать кнопку текущего цвета ракетки. После запуска ракетка получает новый случайный цвет.

- лёгкий и средний уровни: одна дорожка на игрока;
- сложный и экстрим: две разнесённые дорожки на игрока, цвета двух ракеток не повторяются;
- полный путь мяча вверх и обратно изначально занимает 1,5 секунды;
- скорость плавно растёт и достигает заданного уровнем максимума после 20 успешных отбиваний;
- каждое успешное отбивание даёт 1 балл;
- после 15 отбиваний без ошибки включается `X2` на 7 секунд;
- при пропуске мяч возвращается на ракетку и ожидает нового запуска.

Максимальное ускорение: `2×` на лёгком, `2,5×` на среднем, `2×` на сложном и `2,5×` на экстриме.

### Цветовое кольцо

В центре игрового поля вращается кольцо из восьми случайных цветных шариков. Игроки запускают в него шарики цветом своих кнопок с противоположных сторон.

- шарик прикрепляется только при физическом касании другого шарика;
- через пустой промежуток он пролетает насквозь и покидает поле;
- при каждой вставке диаметр кольца немного увеличивается;
- если кольцо содержит больше восьми позиций, после удаления цепочки оно уменьшается вместе с количеством шариков;
- ниже базового размера кольцо не уменьшается: при количестве меньше восьми на нём остаются промежутки;
- если удалены все шарики, первый долетевший до кольца шарик сразу создаёт новую точку;
- цепочка из трёх и более соседних одинаковых цветов удаляется;
- игрок получает по одному баллу за каждый удалённый шарик;
- каждый игрок может запускать новый шарик не чаще одного раза в `500 мс`;
- радиус плавно изменяется, а плотное кольцо автоматически расширяется так, чтобы соседние шарики не перекрывались;
- новые шарики плавно встраиваются со стороны касания, удалённые постепенно уменьшаются;
- центральный прозрачный генератор запускает обычный цветной шарик каждые 3 секунды и бонусный каждые 15 секунд; при промежутке на пути он ждёт подходящего участка кольца;
- простое касание бонуса не активирует его: бонус должен удалиться внутри цепочки из трёх и более шариков того же цвета;
- бонусный шарик отмечен значком: `×2` удваивает очки на 7 секунд, `↺` разворачивает вращение, `↝` перемешивает цвета, `✹` удаляет пять ближайших шариков и начисляет за них очки;
- игра заканчивается по таймеру или при достижении красной границы.

Звуки режима добавляются без изменения кода:

- `music/effects/color-ring/blue-launch` — запуск шариков синего игрока;
- `music/effects/color-ring/orange-launch` — запуск шариков оранжевого игрока;
- `music/effects/color-ring/remove` — варианты звука удаления цепочки, воспроизводимые в случайном порядке.

Поддерживаются файлы MP3, WAV, OGG, M4A и AAC. Пустые папки не мешают запуску игры.

Скорость вращения: один оборот за 5 секунд на лёгком уровне, за 4 секунды на среднем и за 3 секунды на сложном.

## Прошивки

```text
arduino\ColorDuel_LED_Nano\ColorDuel_LED_Nano.ino
arduino\ColorDuel_Sensors_Nano\ColorDuel_Sensors_Nano.ino
```

Для LED установите `Adafruit NeoPixel`. Для датчиков — `HX711`.

Распиновка LED Nano:

```text
D8, D9, D10, D11 — каналы 1–4
D6, D7, A0, A1   — каналы 5–8
```

Расположение каналов и соответствие цветам задаются в режиме техника.

Каждую DATA-линию подключать через 220–330 Ом. Все земли объединить. Ленты питать отдельным БП 5 В; не через Nano.

Sensor Nano использует пары DOUT/SCK:

```text
D2/D3, D4/D5, D6/D7, D8/D9,
D10/D11, D12/D13, A0/A1, A2/A3
```

Первые четыре канала — Player 1, следующие четыре — Player 2. Порядок цветов: RED, GREEN, BLUE, YELLOW.

## Автоопределение COM

Обе прошивки отвечают на `IDENTIFY`:

```text
COLOR_DUEL_LED READY
COLOR_DUEL_SENSORS READY
```

Поэтому приложение не зависит от случайной перестановки COM-портов после перезагрузки Windows. Для ручного назначения замените `auto` на `COMx` в `config.json`.

## StriveX

Color Duel слушает:

```text
ws://127.0.0.1:4210
```

Для его Gateway задайте:

```env
STATION_ID=color-duel-01
ADAPTER=gameserver
GAME_WS_URL=ws://127.0.0.1:4210
```

RFID читает Gateway, не само Electron-приложение. Offline/no-card режим выключен.

## Настройка тензодатчиков

После монтажа и при отсутствии нагрузки отправьте Sensor Nano:

```text
TARE
```

Порог отдельного канала задаётся командой:

```text
THRESHOLD 1 12000
```

Каналы 1–8. Значения нужно подобрать на реальной механике. Прошивка отправляет:

```text
HIT 1 R 18450
HIT 2 Y 20310
```

## Ограничение Arduino Nano

Классический Nano имеет 2 КБ RAM. LED-прошивка специально использует один общий буфер на 60 диодов и последовательно обновляет восемь линий. Одновременно поддерживается до шести бегущих импульсов на каждой линии. Если на реальном стенде частота ударов окажется выше этого запаса, LED-контроллер можно заменить на Mega/RP2040 без изменения протокола ПК.
