Поместите сюда музыку режима «Пин-понг».

Поддерживаются файлы MP3, WAV, OGG, M4A и AAC.
Если файлов несколько, они воспроизводятся по очереди.

Звук успешного отбивания задаётся отдельно параметром `audio.pingPongHit`
в файле `config.json`. По умолчанию используется `music/button.mp3`.
Можно положить свой файл в папку `music` и изменить путь в настройке.

Звук промаха задаётся параметром `audio.pingPongMiss`.
По умолчанию используется `music/bonus1.mp3`; его также можно заменить.
